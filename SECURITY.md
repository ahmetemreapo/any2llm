# Security policy

## Reporting a vulnerability

Request a private contact channel from the maintainer by opening a [GitHub issue](https://github.com/ahmetemreapo/any2llm/issues/new) that only asks how to reach them about a security concern. Share technical details after the maintainer provides a private channel.

In your private report, include the any2llm version or commit, your Python version and operating system, the affected feature, and the impact. Use synthetic sample data and remove credentials, personal information, and document contents from any logs or attachments you share.
