# Security policy

## Reporting a vulnerability

Use the [private vulnerability report form on GitHub](https://github.com/ahmetemreapo/any2llm/security/advisories/new) to share security concerns with the maintainers. You can also find the form under **Security → Advisories → Report a vulnerability**.

In your private report, include the any2llm version or commit, your Python version and operating system, the affected feature, and the impact. Use synthetic sample data and remove credentials, personal information, and document contents from any logs or attachments you share.
