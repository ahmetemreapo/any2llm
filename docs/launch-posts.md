**A Python CLI for packing mixed documents into Markdown**

## r/LocalLLaMA

**English**

**Preparing mixed document folders for a local chat**

I wanted file preparation to happen on my machine and to pick the chat model separately. any2llm produces numbered Markdown files and a prompt for citations and batch order. Working on it made me pay more attention to two things I can actually check: what fits the model’s context and whether a citation points to the right PDF page. If you try the public sample in your local chat, I’d like to hear how it handles the page tags.

## Office and finance community

**English**

**Checking supplier delivery dates across a PDF and a spreadsheet**

I wanted to ask one question across a supplier offer, a spreadsheet, and a meeting note without losing track of where each date came from. In the demo, the spreadsheet and PDF give the shipment dates, while a freight note sits on an image-only page. That’s the detail that made me want the tool to flag missing text.
